# Sangjune An — research homepage

A responsive, dependency-free academic homepage for GitHub Pages.

## Editing

- `index.html`: biography, research, publications, projects, and education.
- `style.css`: responsive layout, colors, and typography.
- `favicon.svg`: browser icon.

No build step, external fonts, analytics, or JavaScript is required. The original CV PDF is not published.

## Local preview

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000.

## GitHub Pages

In repository Settings → Pages, select **Deploy from a branch**, the branch containing these files, and **/ (root)**. The site will be available at https://june0102.github.io/.
