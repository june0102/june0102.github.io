GFlowNets · Prompt optimization

Searching beyond a single solution

How can we explore a large prompt space while making better use of expensive model evaluations?

In GFlowPO, we combine off-policy GFlowNet training with replay and dynamic memory updates to guide prompt search toward promising regions.

arXiv preprint · 2026

GFlowPO: Generative Flow Network as a Language Model Prompt Optimizer

Junmo Cho, Suhan Kim, Sangjune An, Minsu Kim, Dong Bok Lee, Heejun Lee, Sung Ju Hwang, and Hae Beom Lee

Prompt search as posterior inference: reuse evaluated prompts through off-policy training and adapt the search context with diverse and high-reward examples.

My contributions

  • Co-developed the prompt optimization framework and implemented replay-based GFlowNet training.
  • Contributed to Dynamic Memory Update, which adapts the meta-prompt without additional parameter updates in the memory-update step.
  • Conducted comparative experiments and ablations on replay-based training and dynamic memory updates.
